راهنمای باز کردن پرتفولیو | How to open this portfolio
=========================================================

فارسی
-----
۱. روی فایل zip راست‌کلیک کنید و Extract All را بزنید (حتماً اول از حالت فشرده خارج شود).
۲. در پوشه‌ی بازشده، روی index.html دوبار کلیک کنید.
۳. با Google Chrome یا Microsoft Edge باز کنید و به اینترنت وصل باشید (برای فونت‌ها و انیمیشن‌ها).
۴. زبان سایت از دکمه‌ی «فا / EN» بالای صفحه عوض می‌شود.

English
-------
1. Right-click the zip file and choose "Extract All" (do not open it from inside the zip).
2. In the extracted folder, double-click index.html.
3. Use Google Chrome or Microsoft Edge, with an internet connection (fonts and scroll animations load online).
4. Switch language with the "فا / EN" button at the top.
